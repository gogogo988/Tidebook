潮汐 TIDEBOOK · 自托管试用版 1.1.0 · 2026-09-23

在 Windows 11 上运行海钓预约网站

电脑负责运行网站和保存数据；钓友通过临时 HTTPS 网址注册、报名及提交订金凭证。无需购买域名，也不需要在路由器上开放端口。

本包已包含编译好的网页。日常使用只需安装 Node.js 24 LTS 和 cloudflared，不需要安装 pnpm、编译项目或申请 Cloudflare 数据库。此版本使用独立邮箱密码账户，不使用 ChatGPT 模拟登录。
无域名的 Quick Tunnel 是临时测试通道，不保证持续可用；重启通道会产生新网址。先邀请少量钓友测试。长期正式经营应配置固定域名和受管理的通道，或继续使用现有线上站点。此包不会更改现有 tidebook 线上网站，也不会自动导入或同步其账户、预约或图片。
1.0.1 修复：启动脚本使用 Windows PowerShell 完整路径，自动寻找 Node.js，并仅在当前窗口补充命令搜索路径。无需修改系统 PATH。升级时覆盖程序文件即可，保留原 data 文件夹；已创建船长则直接运行 02。
1.1.0 更新：钓友操作最多两层

注册、报名、提交订金在船期列表的一层弹窗内切换。注册增加用户名，报名自动带入，船期卡片显示醒目的订金按钮。新设密码为 6–12 位；已有较长密码仍可登录。旧账户缺省采用邮箱前半段作为用户名，可在“账户 / 用户名 / 密码”修改。

已有部署的升级步骤
  1. 停止 03 通道与 02 网站窗口，运行 04-Backup.cmd 备份。
  2. 将新包解压到临时文件夹，把其中 Tidebook-Windows 内的文件复制到原部署目录，选择替换同名程序文件。不要删除原目录后再解压。
  3. 保留原 data、backups 文件夹及 tools/cloudflared.exe。本包不含这些个人数据和通道程序。
  4. 无需运行 01 初始化。运行 02，启动时自动补充用户名字段，保留账户、船期和预约；浏览器按 Ctrl+F5 刷新。需要外网时再运行 03 并分享新网址。

本次更新为报名流程优化，未验证或修复此前 Windows 通道的 spawn UNKNOWN 报错。

1 · 安装两个工具

  1. 前往 Node.js 官方下载页，选择 Node.js 24 LTS、Windows Installer (.msi)，按电脑架构选择 x64 或 ARM64。按默认设置安装。
  2. 前往 Cloudflare 官方 cloudflared 下载页，下载适合电脑的 Windows 可执行文件。常见 Intel/AMD Windows 11 使用 64-bit / amd64。
  3. 将 cloudflared 下载文件重命名为 cloudflared.exe，稍后放入本包的 tools 文件夹。打开资源管理器“查看 → 显示 → 文件扩展名”，避免误命名成 cloudflared.exe.exe。

Node.js 和 cloudflared 未捆绑在压缩包内。下载安装时需要联网；请使用上方官方链接。若 Node 安装后仍找不到命令，关闭旧终端，重新双击脚本。

2 · 解压到固定文件夹

右键压缩包 → “全部解压”。建议把内部的 Tidebook-Windows 文件夹放在 C:\Tidebook-Windows。不要直接在 ZIP 中双击运行，不要放进临时下载预览目录或多人共享文件夹。

确认文件夹内有 01-Initialize.cmd、02-Start.cmd、server、web、tools。将第一步下载的程序放在 C:\Tidebook-Windows\tools\cloudflared.exe。

3 · 创建首位船长（只做一次）

  1. 双击 01-Initialize.cmd。
  2. 在 Account email 后输入自己的邮箱。
  3. 输入 6–12 个字符的密码，再输入一次确认。密码输入时不会明文显示。请使用与其他网站不同的密码。
  4. 出现 Captain created 表示成功。

首位船长只能在电脑上创建，访客不能通过网站抢占管理员身份。重复初始化会报 Already initialized，不会覆盖原数据。无需在网页里再点击“启用工作台”。

4 · 启动网站

  1. 双击 02-Start.cmd，保持窗口打开。
  2. 出现 Tidebook ready 后，在浏览器打开 http://127.0.0.1:8787/account。
  3. 用刚设置的邮箱密码登录，进入工作台，发布一条未来船期。填写最少/最多人数、每种人数的人均费用、订金和银行账户。

127.0.0.1 只能在这台电脑打开，不能把它发给钓友。此脚本会在服务器进程异常退出时尝试重新启动；主动关闭窗口或按 Ctrl+C 会停止服务。

5 · 开放临时外网网址

  1. 确保网站窗口仍在运行，再双击 03-Public-Link.cmd。
  2. 等待出现 Share this URL: https://…trycloudflare.com。通道建立可能需要一会儿。
  3. 复制完整 HTTPS 网址发给钓友。网址也会写入包根目录的 PUBLIC-URL.txt。
  4. 使用手机关闭 Wi-Fi、切换移动数据后打开网址，验证确实能从外网访问。

外网访问必须同时保持网站窗口和通道窗口开启。不要手工直接启动 cloudflared 替代此脚本：本脚本还会将准确的公网网址写入允许访问的配置。不要修改或放宽服务器的域名校验。

换了临时网址后，钓友需要使用新链接并重新登录，但电脑上的预约数据仍保留。脚本显示网址只代表取得地址，仍需等待连接完成并按上一步用手机验证。

6 · 钓友和船长如何使用

角色操作
钓友打开船期列表，直接点“立即报名”；首次在同一弹窗注册用户名、邮箱和 6–12 位密码。报名默认带入用户名，可修改。报名成功直接显示订金窗口；按银行账户转账后，上传图片凭证或填写参考号。以后在对应船期卡片直接点“提交订金凭证”或“查看 / 更新订金凭证”。全程为船期列表加一层弹窗。
船长在“海钓预约”核实实际到账后确认订金。未交订金者可取消报名并释放名额，取消记录和原因会保留。
最终收费出发后核对已确认预约人数，在船期详情确认实际人数并结算，再核实尾款。实际人数不能低于最低人数，须与已确认预约相符。
钓获和统计结束船期后发布钓获与照片；通过统计和 CSV 导出查看记录。

网站不读取银行流水，不会自动扣款或退款；照片凭证不代表实际到账。

添加第二位船长 / 转交权限

  1. 接收人先注册、登录，并在 /account 页面查看“接收船长权限”的账户码。
  2. 通过双方已有的电话或聊天方式，把邮箱和账户码交给现任船长。
  3. 现任船长在“工作台设置 → 船长权限”填入这两项，添加第二位船长，或修改现有席位的邮箱并确认转交。

最多两位船长，均具有工作台管理权限。转交后原账户失去船长权限；系统禁止删除最后一位船长。当前未接入验证邮件，邮箱本身不构成身份验证，因此必须核对账户码及实际接收人。

忘记密码

普通钓友联系船长，船长核实身份后，在服务器电脑双击 05-Reset-Password.cmd，输入该账户邮箱和新密码。该操作会撤销此账户所有旧登录。首位船长忘记密码也可在本机通过同一脚本恢复。此版本不发送找回密码邮件。

7 · 保持运行与自动启动

接通电源，在 Windows“设置 → 系统 → 电源和电池 → 屏幕和睡眠”中，将接通电源时的睡眠设为“从不”。屏幕可以关闭，电脑不能睡眠或关机。合盖是否睡眠需要按电脑的电源设置确认。

可选：双击 06-Enable-Autostart.cmd，给当前 Windows 用户添加登录后自动启动网站的快捷方式。不是开机前的 Windows 服务，必须先登录 Windows；临时外网通道仍需手动运行 03-Public-Link.cmd，并分享新网址。

双击 07-Disable-Autostart.cmd 可移除自动启动快捷方式。它不会关闭当前正在运行的网站。启用自动启动后不要移动部署文件夹；如要移动，先移除，移动后重新启用。

8 · 备份、恢复与迁移电脑

数据保存在包内 data：tidebook.sqlite 保存账户和业务记录，files 保存图片。它与旧开发版的 .wrangler 格式不同，不能直接混用。

  1. 关闭通道窗口，在网站窗口按 Ctrl+C 停止网站。
  2. 双击 04-Backup.cmd。完成后会显示备份路径，在 backups\时间戳 中。
  3. 将该整个时间戳文件夹复制到另外的硬盘。备份包含账户哈希和个人资料，请妥善保管。
  4. 重新运行 02 和 03 脚本。

恢复：停止网站与通道，先把当前 data 文件夹改名为 data-before-restore 保留原件；创建新的 data 文件夹，将备份内的 tidebook.sqlite 和 files 复制进去，再启动网站和通道。不要在服务运行时直接替换数据库文件。恢复将回到备份时的数据状态。

迁移到新电脑：安装 Node.js 和 cloudflared，复制部署包，按上述方式恢复数据。不要再次初始化；已有船长账户会随数据库恢复。本包提供手动备份脚本，未自动创建定时备份任务。

9 · 常见问题

现象处理
node 不是内部或外部命令安装 Node.js 24 LTS，重新打开脚本。可在终端运行 node --version 检查。
cloudflared not found确认 tools\cloudflared.exe 存在且名称正确；也可安装到系统 PATH。
外网 502 / 打不开确认 02 窗口正常、本机 8787 可打开、03 窗口仍在连接、手机使用最新网址。网络需允许 cloudflared 出站连接。
Unrecognized host / Origin rejected用 03 脚本提供的原始 HTTPS 网址访问，不要自改域名、使用旧网址或加端口。不要关闭域名或来源校验来绕过错误。
Quick Tunnel 不启动查看错误；已有 .cloudflared/config.yaml 可能与临时通道冲突。先备份并了解原配置用途，不要直接删除现有通道配置。
邮箱密码错误 / 重复注册本站账户独立于 ChatGPT。使用本站注册密码；忘记密码由船长在本机核实后重置。
尝试过于频繁登录等账户操作有频率限制，等待 15 分钟再试。
电脑重启或断网恢复联网后重新启动网站和通道，发送新的临时网址；数据仍在 data 中。
Windows 阻止文件先确认文件来自本次下载。可在文件属性查看是否有“解除锁定”；组织策略限制时请联系管理员，不要关闭系统防护。

10 · 包内文件与验证范围

文件用途
01–07 的 .cmd 脚本初始化、启动、外网通道、备份、重置密码、登录后自启及移除自启
web / server已编译网页及独立 Node.js 服务；日常使用不需要安装 npm 依赖

已在 Linux 环境的 Node.js 24 上通过接口集成检查：真实登录、会话、账户数据隔离、凭证访问控制、满员拒绝与取消再报名、按人数结算、双船长及接收码、权限撤销、请求来源和域名校验、密码修改、HTTPS Cookie 与备份读取。还验证了旧账户结构自动升级、旧密码登录、用户名缺省带入与修改、6–12 位密码边界。网页已完成生产编译和 TypeScript 检查；当前环境未能下载浏览器，尚未完成浏览器交互实测。

未实测：Windows 11 双击脚本、Windows 自动启动、公网 cloudflared 通道及你所在网络的连通性。此包为可运行的自托管试用版本，不是已经替你安装好的电脑服务。首次对外使用请按本说明完成手机移动网络检查及小范围试用。

开发人员重建：在 source 文件夹用 package.json 指定的 pnpm 版本安装锁定依赖，再回到包根目录运行 node tools/build.mjs。日常用户不需要此步骤。后端不依赖 Cloudflare Workers，也不信任来访请求提供的 ChatGPT 身份头。
